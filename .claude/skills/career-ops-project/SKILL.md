# career-ops project -- Portfolio Project Evaluation

Score a project idea across 6 dimensions for maximum interview impact.

## Input

`{{project_idea}}` — Project name, description, or concept.

## Execution

Read and execute the full instructions in `modes/project.md`. Scores:
- Signal for target roles (25%)
- Uniqueness (20%)
- Demo-ability (20%)
- Metrics potential (15%)
- Time to MVP (10%)
- STAR story potential (10%)

Verdict: BUILD / SKIP / PIVOT + 80/20 plan.
