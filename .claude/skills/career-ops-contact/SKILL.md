# career-ops contact -- LinkedIn Power Move

Find hiring managers, recruiters, and peers at a target company, then draft a personalized LinkedIn connection message.

## Setup

1. Read `modes/_shared.md` for global rules
2. Read `modes/_profile.md` for user narrative
3. Read `cv.md` for proof points
4. Read `config/profile.yml` for candidate context

## Input

`{{company_and_role}}` — Company name and role title.

## Execution

Read and execute the full instructions in `modes/contacto.md`:
1. WebSearch to identify hiring manager, recruiter, and 2-3 peers
2. Select primary target
3. Draft 300-char LinkedIn message (hook + proof + proposal)
4. Provide alternative targets with justification
