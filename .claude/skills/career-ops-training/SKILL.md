# career-ops training -- Course/Cert Evaluation

Evaluate whether a course or certification is worth the time investment.

## Input

`{{course_description}}` — Course name, URL, or description.

## Execution

Read and execute the full instructions in `modes/training.md`. Evaluates 6 dimensions:
- North Star alignment
- Recruiter signal
- Time and effort
- Opportunity cost
- Risks
- Portfolio deliverable

Verdict: HACER / NO HACER / HACER CON TIMEBOX + plan.
